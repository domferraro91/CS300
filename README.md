# CS300

What was the problem you were solving in the projects for this course?

The problem that I was solving with the projects in this course was finding the correct and most efficient data structure to use depending on the information that was to be sorted. For Project Two, I chose using Hash Tables as the most efficient way of sorting courses. 

How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by examining run-times of hash tables, vectors, and binary search trees, and also going over their advantages and disadvantages. I wanted fast searches, which hash tables provided. A binary search tree may have also provided a fast search, as long as the tree was balanced, but I looked at the data that was being stored and chose the hash table as the best choice. Data structures are important to understand because each one operates differently, and each one has its own place of when it should be used. The data that is to be stored should be examined and questioned on how often the data will be inserted or removed, how often searches are performed, whether it needs to be in order, and many other factors. 

How did you overcome any roadblocks you encountered while going through the activities or project?

Any roadblocks that I encountered, I ended up going through the material on ZyBooks again, or doing my own independent research online through websites such as Stack Overflow and others.

How has your work on this project expanded your approach to designing software and developing programs?

This project showed me how data structures work and how there is an actual measurable time difference when using different data structures on the same set of data, and how the data should be examined to carefully choose what structure should be used.

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

Completing this project improved my pseudo-code as well as my in-line comments on my code to ensure that the code can be understood. It also showed me to make my code in blocks, so that if something needs to be changed for the program (adaptable), then only a limited amount of blocks need to be changed and not the entire system of code. Keeping the code in blocks also improves readability as different functions are intertwined with each other, causing confusion, and allows for easier maintainability because the functions can be easily found.
